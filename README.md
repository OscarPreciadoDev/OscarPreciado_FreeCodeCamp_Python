# Python - FreeCodeCamp

Este repositorio contiene los ejercicios, prácticas y proyectos que voy desarrollando 
como parte del curso de **Python** de [freeCodeCamp](https://www.freecodecamp.org/).

## 🎯 Objetivo

Documentar mi proceso de aprendizaje de Python, desde los conceptos básicos hasta 
temas más avanzados, sirviendo como referencia personal y registro de progreso.

## 📂 Contenido

- Fundamentos de Python (variables, tipos de datos, estructuras de control)
- Funciones y manejo de errores
- Programación Orientada a Objetos (POO)
- Estructuras de datos
- Proyectos prácticos del curso

## 🛠️ Tecnologías

- Python 3.x

## 📌 Notas

Este repositorio es de carácter educativo y refleja mi progreso personal en el curso. 
El código puede no estar optimizado, ya que forma parte del proceso de aprendizaje.
